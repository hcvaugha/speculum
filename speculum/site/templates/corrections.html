Corrections

Speculum is a record, and a record is only as good as its corrections. Nothing here is changed silently: every fix is logged below with the date, what was wrong, and what changed.

What happens next

  1. We check the figure against the original filing, which is archived for every night.
  2. If it is wrong, we fix the cause, not only the number, so the same error cannot return the next night.
  3. We log the correction here. If the error changed what a page said about someone, the page itself notes the correction.
  4. If it is right, we reply with the filing that shows it.
